# Хранители Времени — Windows

## Установка и сборка:

1. Установи Node.js (https://nodejs.org — версия 18+)

2. Открой терминал в этой папке и запусти:
   ```
   npm install
   npm start          # запуск для теста
   ```

3. Сборка EXE:
   ```
   npm run build              # .exe установщик
   npm run build-portable     # портативная версия (без установки)
   ```

4. Готовые файлы появятся в папке `dist/`:
   - `Хранители Времени Setup 1.0.0.exe` — установщик
   - `Хранители Времени 1.0.0.exe` — портативная версия

## Для публикации:
- Можно залить на itch.io, Google Drive, или собственный сайт
- Не нужен сертификат разработчика (в отличие от App Store)
- Работает на Windows 10/11
